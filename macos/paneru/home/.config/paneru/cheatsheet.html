Paneru cheat sheet

fn is Mod (niri-style)  ·  grey column = backup using the real left ⌃ + ⌥
fn Globe⌃ Control⌥ Option ⌘ Command⇧ Shift

Focus

fn←/→Focus window left / right⌃⌥,.
fn↑/↓Up / down in stack, then switch row⌃⌥↑↓
fn⌥←/→Jump to first / last window

Rows (virtual workspaces)

fn123Go to row 1 / 2 / 3⌃⌥1–3
fn⇧123Move window to row 1 / 2 / 3⌃⌥⇧1–3
fn⇧↑/↓Move window to row above / below⌃⌥⇧↑↓

Rows are created past the last one and removed when empty.

Move

fn⇧←/→Move window left / right⌘⌃⌥,.
fn⌥↑/↓Move up / down within a stack⌘⌃⌥↑↓
fn⌥⇧←/→Move window to first / last

Size

fn⌘←/→Narrower / wider (50–100%)⌃⌥[]
fn-/=Narrower / wider (niri style)
fn⌘↑/↓Taller / shorter (in a stack)
fnForfn⇧FToggle full width⌃⌥'
fnCCenter window⌃⌥C
fnBBalance all columns to this width⌃⌥B

50/50 split: narrow one window to 50%, then fnB.

Stack & float

fn,Stack into column on the left⌃⌥S
fn.Pull out of the stack⌃⌥U
fnEEqual heights in the stack⌃⌥E
fnSpaceToggle tiled / floating⌃⌥;
⌃⌥QQuit Paneru

Always floating: Calculator, QuickTime, AppCleaner, KeyboardCleanTool.

Trackpad & mouse

3-finger ← →Slide through windows
3-finger ↑ ↓Switch row
⌥ + scrollSlide windows
⌥⌘ + scrollSwitch row

Keep macOS Mission Control / full-screen swipes on 4 fingers.

Config: ~/.config/paneru/paneru.toml  ·  Restart: paneru restart  ·  Reopen this: paneru-help  ·  Close a window: ⌘W

fn works because System Settings → Keyboard Shortcuts → Modifier Keys maps Globe to Control (seen by Paneru as right Control). Changing that setting breaks every fn shortcut.
